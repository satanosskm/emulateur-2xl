# Émulateur robot 2-XL 2.1.2

## Téléchargement

Décompresse `Emulateur-2XL-2.1.2-windows.zip` puis lance `Emulateur-2XL.exe`.

## Nouveautés

- Boutons A, B et C affichés à côté des réponses NON, VRAI et FAUX.
- Bouton principal qui alterne entre Lecture, Pause et Reprendre.
- Interface recentrée et palette plus sobre.
- Nom du projet : Émulateur robot 2-XL.
